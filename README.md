# ResQDrive (SIH Prototype)

This repository is being built in phases. **Phase 1 (current)** covers AI
dataset preparation and YOLO model training/validation/testing only — see
[`docs/PHASE1.md`](docs/PHASE1.md) for full details, dataset sources, model
choice, how to run the training notebooks, and current status.

Backend, database, frontend, routing, and dashboard work are later phases
and have not been started.
